## 临时免登录

前端默认跳过登录/注册页面，不生成伪造 JWT，也不发送以前保存的 token。恢复前端登录门禁：

```bash
VITE_AUTH_DISABLED=false npm run dev
# 正式构建时同样需要传入 VITE_AUTH_DISABLED=false
```

原后端已经跳过认证。本次将该行为改为可配置，并统一 g.user_id 与 session['user_id']，修复免登录上传和保存缺少用户身份的问题。默认使用 ID=1 的现有有效账户，可通过 DEMO_USER_ID 指定；没有该账户时返回 503，不自动创建或冒用其他账户。恢复后端验证需设置 AUTH_DISABLED=false 并重启。前后端开关需要同时恢复。
